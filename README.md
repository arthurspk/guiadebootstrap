## :dart: O guia para alavancar a sua carreira

> Bootstrap é o framework CSS mais usado do mundo para construir interfaces responsivas rápido: grid de 12 colunas, componentes prontos (navbar, modal, carrossel, formulários) e um sistema de utilitários que resolve boa parte do layout sem escrever CSS do zero. Na versão 5, ele deixou de depender do jQuery, ganhou variáveis Sass/CSS customizáveis e um conjunto de ícones próprio. Este guia reúne documentação oficial, cursos gratuitos e pagos, canais, ferramentas do ecossistema (temas, admin templates, integrações com React/Vue/Angular), projetos práticos e comunidades para quem está montando sua primeira interface até quem já usa Bootstrap em produção e quer dominar customização e Grid moderno. Os recursos em português e gratuitos vêm primeiro em cada seção, e todo link foi verificado. Use-o como apoio para os seus estudos, no seu ritmo.

## 🗺️ Roadmap

- [roadmap.sh — Frontend Roadmap](https://roadmap.sh/frontend) — O caminho completo de front-end em que um framework CSS como o Bootstrap se encaixa, ao lado de HTML, CSS e JavaScript.
- [Milestones do Bootstrap no GitHub](https://github.com/twbs/bootstrap/milestones) — O que a equipe do Bootstrap está preparando para as próximas versões, direto do repositório oficial.
- [Versões do Bootstrap](https://getbootstrap.com/docs/versions/) — Histórico de todas as versões, da 2 à 5, com o que mudou em cada uma.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **HTML e CSS básicos** — o Bootstrap é uma camada sobre CSS puro; domine seletores, box model e Flexbox antes de começar.
2. **Instalação e estrutura** — via CDN ou `npm install bootstrap`, o container, o sistema de grid de 12 colunas e os breakpoints responsivos.
3. **Grid system** — `container`, `row`, `col`, colunas automáticas, offsets e ordenação em telas diferentes.
4. **Componentes prontos** — navbar, cards, modais, carrossel, accordion, tooltips e toasts.
5. **Formulários** — controles, validação visual, grupos de input e layouts em grid.
6. **Classes utilitárias** — espaçamento (`m-*`/`p-*`), cores, flexbox helpers, display e visibilidade responsiva.
7. **Customização com Sass** — variáveis, mapas de cores, recompilar o Bootstrap com sua própria paleta em vez de sobrescrever CSS.
8. **Bootstrap Icons e temas** — ícones SVG oficiais e temas prontos (Bootswatch, Creative Tim) para acelerar o visual.
9. **Integração com frameworks JS** — usar os componentes com React (React-Bootstrap), Vue (BootstrapVue) ou Angular (ngx-bootstrap) sem depender do JavaScript nativo do Bootstrap.

**Por onde começar:**

1. **Leia a introdução oficial** em [Get started with Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/introduction/) — como incluir via CDN em 5 minutos.
2. **Copie um exemplo pronto** em [Examples](https://getbootstrap.com/docs/5.3/examples/) e mexa nele no navegador para entender a estrutura.
3. **Aprenda o grid brincando** com o [Learn Bootstrap (Scrimba)](https://scrimba.com/learn-bootstrap-c0o), curso interativo gratuito.
4. **Faça um curso guiado em português**: [Bootstrap: grid e fundamentos (Alura)](https://www.alura.com.br/curso-online-bootstrap-grid-fundamentos).
5. **Pratique em vídeo** com os canais [Curso em Vídeo](https://www.youtube.com/@CursoemVideo) e [Matheus Battisti — Hora de Codar](https://www.youtube.com/@MatheusBattisti), que têm conteúdo de Bootstrap.
6. **Troque um template pronto** do [Start Bootstrap](https://startbootstrap.com/templates) e adapte para um projeto seu.
7. **Construa um desafio real** no [Frontend Mentor](https://www.frontendmentor.io/) usando somente classes do Bootstrap.
8. **Publique no GitHub** — seu primeiro item de portfólio com Bootstrap de verdade, linkado no currículo.

Sua primeira página em 30 segundos:

```html
<!-- index.html -->
<!doctype html>
<html lang="pt-br">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <link
      href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
      rel="stylesheet"
      integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB"
      crossorigin="anonymous"
    />
  </head>
  <body>
    <div class="container py-5">
      <h1 class="text-primary">Olá, Guia Dev Brasil!</h1>
      <button class="btn btn-primary">Comece aqui</button>
    </div>
    <script
      src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"
      integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI"
      crossorigin="anonymous"
    ></script>
  </body>
</html>
```

Abra o `index.html` no navegador — o `container`, o texto colorido e o botão já vêm estilizados pelo Bootstrap, sem escrever uma linha de CSS.

## 🤖 IA na prática

Bootstrap é um dos temas em que a IA mais "alucina" nomes de classes de versões antigas: ela mistura sintaxe do Bootstrap 3/4 (`.form-group`, `.pull-right`, `data-toggle`) com a do Bootstrap 5 (`.row-cols`, `.float-end`, `data-bs-toggle`), o que quebra o layout silenciosamente. Use a IA como **acelerador de HTML repetitivo**, não como fonte de verdade sobre qual versão do framework você está usando.

**Para aprender**
- Peça para **explicar um componente com um exemplo executável**: diferença entre `container` e `container-fluid`, como funciona `col-md-6 col-lg-4`, ou o que muda em `d-flex justify-content-between`. Cole o exemplo em um [StackBlitz](https://stackblitz.com/) ou no [JSFiddle](https://jsfiddle.net/) para ver rodando.
- Cole um layout quebrado e peça: *"por que essas colunas não estão alinhando no Bootstrap 5?"* — depois confirme a resposta na [documentação oficial do Grid](https://getbootstrap.com/docs/5.3/layout/grid/).
- Peça para **migrar um trecho de Bootstrap 4 para 5**, explicando cada classe trocada (ex.: `ml-*`/`mr-*` → `ms-*`/`me-*`, `data-toggle` → `data-bs-toggle`), e confirme com o [guia oficial de migração](https://getbootstrap.com/docs/5.3/migration/).
- Peça **exercícios com gabarito** sobre o tópico que está estudando (grid, formulários, utilitários) e resolva antes de olhar a resposta.

**Para trabalhar**
- Use [GitHub Copilot](https://docs.github.com/pt/copilot), [Cursor](https://cursor.com/), [Claude Code](https://code.claude.com/docs/en/overview) ou [Gemini CLI](https://github.com/google-gemini/gemini-cli) para gerar a marcação HTML de componentes Bootstrap (navbar, cards, formulários), revisar classes desatualizadas e escrever variações responsivas mais rápido.
- Ferramentas de **design para código** como [v0 (Vercel)](https://v0.app/), [Builder.io](https://www.builder.io/) e [21st.dev](https://21st.dev/) geram interfaces a partir de um prompt — o resultado costuma vir em Tailwind, então se você precisa de Bootstrap peça explicitamente "usando classes do Bootstrap 5" e revise antes de usar.
- Depois de **cada** sugestão aceita, confira no navegador em telas pequenas e grandes — a IA raramente testa se o `container` está de fato responsivo, e menos ainda se as classes existem na versão do Bootstrap que você instalou.
- Peça sempre a versão: "estou usando Bootstrap 5.3, sem jQuery" muda completamente a resposta em relação a projetos legados em Bootstrap 3/4.

**Limites e boas práticas**
- A IA **mistura classes de versões diferentes** do Bootstrap com frequência. Confirme sempre na [documentação oficial](https://getbootstrap.com/docs/5.3/getting-started/introduction/), que lista a versão exata de cada exemplo.
- Ela tende a sugerir dependência de jQuery ou plugins antigos quando o Bootstrap 5 já resolve o mesmo problema com JavaScript puro (Popper.js embutido).
- Peça para **explicar o "porquê"** de cada classe usada — entender o grid e os utilitários evita "gambiarras" de CSS customizado por cima do framework.
- Não cole design proprietário ou tokens de marca de clientes em ferramentas sem a política da sua empresa.
- Entenda o que você aceita: em entrevista e em produção, o HTML/CSS é seu — e quem mantém o projeto depois é você.

**Ferramentas de IA úteis no dia a dia com Bootstrap:**
- [GitHub Copilot — documentação (PT-BR)](https://docs.github.com/pt/copilot) — Assistente de código integrado ao VS Code; gratuito para estudantes e com plano free limitado.
- [Cursor](https://cursor.com/) — Editor baseado no VS Code com IA para editar, refatorar e conversar com o projeto, incluindo templates Bootstrap.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal: entende o repositório inteiro, útil para migrar projetos Bootstrap antigos.
- [Gemini CLI](https://github.com/google-gemini/gemini-cli) — Agente open source do Google no terminal, com cota gratuita generosa.
- [v0 (Vercel)](https://v0.app/) — Gera interfaces a partir de um prompt — bom para prototipar e depois adaptar para classes do Bootstrap.
- [Builder.io](https://www.builder.io/) — Converte designs (inclusive do Figma) em código, útil como ponto de partida para telas em Bootstrap.
- [21st.dev](https://21st.dev/) — Biblioteca de componentes de UI gerados com IA, úteis como referência visual antes de montar no Bootstrap.
- [Galileo AI](https://galileo.ai/) — Gera telas de interface a partir de um prompt, útil para explorar layouts antes de montar o HTML.
- [Relume](https://www.relume.ai/) — Gera wireframes e componentes de site com IA, exportáveis com estilos prontos.
- [Uilabs](https://www.uilabs.dev/) — Coleção de componentes de UI abertos, com variações geradas para estudar padrões de layout.
